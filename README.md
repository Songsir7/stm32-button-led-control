# stm32-button-led-control

基于 STM32F103C8T6 的按键控制 LED 入门示例项目。

当前分支为：

```text
v1.0-buggy
```

该分支用于记录项目最初版本中发现的按键控制问题。

---

## 功能目标

本版本原计划实现两个独立按键分别控制两个 LED。

预期效果如下：

```text
按住 PA8，LEDA0 亮
松开 PA8，LEDA0 灭

按住 PA11，LEDC14 亮
松开 PA11，LEDC14 灭
```

当两个按键同时按下时，预期两个 LED 都能正常点亮；松开其中一个按键时，只熄灭对应的 LED。

---

## 已发现问题

实际测试时发现，两个按键没有真正做到独立控制。

具体表现为：

```text
先按下 PA8 不松手，
再按下 PA11，
LEDC14 不会亮。
```

也就是说，当 PA8 已经被按下时，PA11 的按键状态无法被正常识别。

反过来测试时，又出现了不同表现：

```text
先按下 PA11 不松手，
再按下 PA8，
LEDC14 可以保持亮。
```

这个现象说明当前程序的按键检测逻辑存在问题，两个按键之间并没有完全独立。

---

## 问题总结

当前版本存在的主要问题：

- 两个按键不能稳定独立控制两个 LED
- 同时按下两个按键时，只能优先识别其中一个按键
- 按键状态之间存在互相影响
- 当前按键检测逻辑不适合处理多个按键同时按下的情况
